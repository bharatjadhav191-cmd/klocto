# Apexjov V63 – Color Themes + Multilingual Website Builder

## User-requested improvements
- Added 12 selectable website color themes:
  Ocean Blue, Sunset Orange, Emerald Green, Royal Purple, Rose Pink, Midnight, Sand/Luxury, Teal, Fresh Lime, Berry, Monochrome, Sky.
- Website templates now ship with varied default color themes instead of repeating the same palette.
- Template Preview now has live **Color Theme** selector.
- Template Preview now has live **Website Language** selector:
  - English
  - हिन्दी
  - मराठी
- Preview refreshes immediately when theme/language changes.
- Selected theme + language are carried into **Use This Template** and saved into the created website draft.
- Website editor now includes Color Theme + Language controls.
- Direct/offline training mode local website editor also includes the same controls and can save a local draft.
- Common website navigation, CTA, enquiry, service, trust and testimonial text is translated for Hindi/Marathi previews.
- Existing 40 distinct business website templates are preserved.
- Existing Forms/Funnels/CRM/other portal modules are not removed.
