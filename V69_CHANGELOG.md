# V69 — External AI Design Import + Publish Testing

Added to the V68 testing portal:
- Import website / landing page / funnel designs created in external AI tools or custom HTML.
- Upload an `.html/.htm` file or paste HTML into the portal.
- Imported design is saved in the agency browser's Apexjov template library for testing/reuse.
- Imported website/landing/funnel design can be opened for editing and saved as a customer website draft.
- Hero/About image upload/change works with imported designs.
- Existing public publishing flow remains available for imported website drafts.
- Public renderer supports imported HTML with basic script/event-handler/javascript-URL sanitization for staging.
- Existing V68 modules are preserved; this is additive testing functionality.

Important: an arbitrary external AI design is imported as HTML. Full drag-and-drop conversion of every possible AI builder's proprietary format is not guaranteed; exported HTML is the supported universal import format in this testing build.
